# Beavers Tree Service & Landscaping Inc.

Professional tree removal, trimming, landscaping, and emergency storm services in the Raleigh-Durham Triangle area of North Carolina.

Licensed, insured, and family owned with over 20 years of experience.

## Development

**Prerequisites:** Node.js

1. Install dependencies:
   ```
   npm install
   ```
2. Run the app:
   ```
   npm run dev
   ```
3. Build for production:
   ```
   npm run build
   ```

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion
- React Router
